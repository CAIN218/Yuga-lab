AudioSwitcher

Windowsの音声出力を、ショートカットキーひとつで切り替え

Overview

AudioSwitcherは、スピーカー、ヘッドセット、外付けDACなどの音声出力先を、ショートカットキーひとつで切り替えられるWindows常駐アプリです。ゲームや通話の途中にサウンド設定を開く必要はもうありません。

Features

シンプルな3つのタブ

画面は3つのタブに分かれています。A/B Switch では2台の出力先の切り替え、Multi-Device では出力先の一覧から選んでの切り替え（一覧に出すデバイスも1台ずつ選べます）、Settings ではスタートアップ登録やアップデートの設定ができます。

アニメーションつきのチュートリアル

? ボタンを押すと、番号つきの説明、操作する場所を示す枠、クリックの動きで、使い方を1ステップずつ案内します。Settings タブからも開けます。

ひと目でわかる切り替え通知

切り替えると、画面右下に小さなカードが表示され、ヘッドホンやスピーカーのアイコンと新しい出力先の名前を知らせてから消えます。作業の邪魔をせずにどのデバイスになったかがわかり、アップデートがあるときもここでお知らせします。

同じ名前のデバイスも正しく区別

Windowsでは、製品名が同じオーディオデバイスを取り違えることがよくあります。AudioSwitcherはWindows Core Audio API（pycaw経由）から各デバイス固有のIDを取得して区別するため、確実に目的のデバイスへ切り替わります。

Windowsの起動時に自動で常駐

Settings タブでオンにすると、Windowsのスタートアップフォルダーに自分自身を登録します。Pythonスクリプトでも単体の.exeでも動作するので、サインインするたびにバックグラウンドで待機します。

英語と日本語に対応

Settings タブの「Language / 言語」から表示言語を選べます。切り替えるとすぐに画面が変わり、保存前の入力内容もそのまま残ります。初期設定は英語です。

What's included

  • AudioSwitcher.exe — アプリ本体です。デバイスの制御まで含めて、これ1つで動作します。
