Lumina

Brightness control for multi-monitor Windows setups, right from the taskbar

Overview

Lumina lives in your taskbar and lets you change the brightness of any monitor that supports DDC/CI. Click the tray icon and a panel opens with one slider for each connected display. No more digging through Control Panel or pressing the buttons on each monitor.

Features

A clean slider panel in the tray

Click the tray icon and the panel fades and slides into view, with a slider for each monitor. Rounded corners, a soft glow on the handle while you drag, and the same calm dark design as the other Yuga's lab apps make it feel more polished than the usual tray utility.

Adjust monitors one by one or all at once

Each slider always controls its own monitor. Turn on “Link sliders together” from the right-click menu to add a master slider that moves every monitor at once.

Smooth dragging, even on slow monitors

A DDC/CI command can take up to about 100 ms. Lumina keeps only the latest target value for each monitor and sends it from a background thread, so the slider never lags behind your mouse.

A tray icon you can always see

The icon switches between a light and a dark version to match your taskbar, so it never disappears on a light taskbar. Change Windows' color mode and the icon follows right away.

Updates itself

Lumina checks GitHub for new versions and lets you know when one is out. Update in one click, or turn on Auto-update from the right-click menu. You can also see what changed with “What's New”, and the menu shows the version you're running.

English or Japanese

Choose the display language from Language in the right-click menu. English is the default.

What's included

  • Lumina.exe — The entire app. It runs from the taskbar and needs nothing else installed.
  • README.md — How to use it, with a description of every menu option.

About the Windows SmartScreen warning

Lumina isn't code-signed, so Windows may show a SmartScreen warning the first time you run it. Download and run it at your own risk. The full source code is on GitHub if you'd like to check it first.
